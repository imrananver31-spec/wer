# Семён — портфолио

Личный сайт-портфолио с 3D-сценой на Three.js в духе [igloo.inc](https://www.igloo.inc/).
Ледяной кристалл по скроллу разлетается на ~1900 осколков, и они собираются в новую форму для каждой секции:

| Секция   | Что происходит в сцене                                        |
| -------- | ------------------------------------------------------------- |
| Главная  | стеклянный кристалл кварца со светящимся ядром                |
| Обо мне  | кристалл раскалывается, осколки кружат облаком                |
| Проекты  | осколки выстраиваются в наклонное кольцо, при наведении на проект оно светится |
| Стек     | поле ледяных шипов-«эквалайзер», волна идёт за курсором       |
| Контакт  | осколки собираются в сферу-жеоду вокруг кристалла             |

## Технологии

- **Three.js** — сцена, `MeshPhysicalMaterial` с transmission и iridescence, `InstancedMesh` для осколков
- **GLSL** — небо с северным сиянием, снег на частицах, финальный проход: хроматическая аберрация от скорости скролла, зерно, виньетка
- **Postprocessing** — `EffectComposer` + `UnrealBloomPass` + `OutputPass` (ACES tone mapping)
- **Lenis** — плавный скролл
- **Vite** — сборка

Ещё есть: прелоадер, расшифровка текста «как в терминале», кастомный курсор, HUD с координатами камеры и FPS, адаптивное снижение разрешения на слабых видеокартах, мобильная версия и уважение к `prefers-reduced-motion`.

## Запуск

```bash
npm install
npm run dev          # http://localhost:5173
npm run build        # сборка в dist/
npm run build:single # весь сайт в одном index.html (dist-single/)
```

## Как заполнить своими данными

Весь текст лежит в [`src/content.js`](src/content.js): имя, описание, проекты, стек и контакты.
Сейчас там заглушки, замени их на свои. Ссылки проектов (`url: '#'`) тоже поменяй на настоящие.

## Деплой на GitHub Pages

В репозитории уже есть workflow [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml).
Один раз включи Pages: **Settings → Pages → Source: GitHub Actions**.
После этого каждый пуш в `main` сам собирает сайт и выкладывает его на
`https://imrananver31-spec.github.io/wer/`.

## Структура

```
src/
  content.js          тексты и данные
  main.js             скролл, прелоадер, курсор, HUD
  style.css
  ui/                 рендер секций, эффект расшифровки текста
  scene/
    World.js          рендерер, камера, ключевые кадры по секциям
    Crystal.js        стеклянный кристалл
    Shards.js         осколки и их 5 формаций
    Snow.js           частицы снега
    Background.js     небо с сиянием
    Post.js           постобработка
```
